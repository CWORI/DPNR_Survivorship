Update flow

From TagLab exports to GitHub Pages

  1. 01

    Edit plot config rows under config/outplant_interval_files/ or config/all_coral_survey_files/.

  2. 02

    Render the Quarto website so processed data, output tables, figures, and docs/ are rebuilt together.

  3. 03

    Review file-audit and QA/QC tables before interpreting the plots or publishing the update.

  4. 04

    Run Rscript scripts/pre_push_check.R, then commit and push source, outputs, and rendered site files.
